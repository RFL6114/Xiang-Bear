《湘味寻踪》街道与捏合烹饪更新包

本次目标
- 街道换为手绘水彩古镇市集全景背景；保留原来的小熊、地图框、商店提示与行走控制。
- 小熊图片尺寸有上限，不会再按原图尺寸铺满街道。
- 只保留 3 种食材（五花肉、鲜辣椒、青菜）和 2 种调味（老抽、豆豉辣酱）。
- 摄像头里显示捏合点定位圆点；对准插画并保持捏合后拿取，移动到炒锅上方松开下料。
- 小熊第一次走入店门附近时会停一下，门口捏合需要保持约半秒，必须先靠近店门出现提示才会进入；重新握拳可以继续走过店铺。
- 至少投放两样（至少含一种食材）并翻炒一次后，可点击“完成出锅”生成成品名称、插画、配料明细和评分。

安装步骤
1. 先备份项目根目录里的 gameplay.html、gameplay.css、gameplay.js。
2. 解压本 ZIP 到项目根目录（例如 D:\hunan flavour xiong），允许覆盖这三个同名文件。
3. 把 ZIP 内新增的 assets/scene、assets/food-illustrations、assets/finished-dishes 文件夹合并到项目现有 assets 文件夹。
4. 不要删除整个 assets 文件夹，也不要覆盖或删除你现有的 assets/character/bear-side.png；小熊素材继续使用原来的文件。
5. 用原来的本地网页运行方式打开 gameplay.html。摄像头功能需要 localhost 或 HTTPS，并允许浏览器使用摄像头。

操作测试
街道：握拳持续行走，张开手掌停止；单独伸食指横向指向左 / 右转向；走到门前出现提示后，拇指与食指捏合保持约半秒进入。
烹饪：摄像头开启后，工作台里的“捏合定位圆点”会跟随手的位置。先将圆点放在左侧食材插画或右侧酱料瓶/碗上，捏合并保持约 0.17 秒拿起；保持捏合移动到中央炒锅，再松开下料。点击“翻炒”或伸三指翻炒，火候按钮可调整火力。至少加入两样并翻炒一次，再点击“完成出锅”。

如果捏合目标仍不准
- 确认页面已获得摄像头权限，手和拇指 / 食指都在画面内。
- 以工作台中的圆点作为实际定位，不要以摄像头小预览里的手的位置直接估算。
- 如果左右方向反了，先不要改 CSS；请记录“向画面左指时角色实际朝哪边”，再进行一次有依据的映射调整。

注意
本更新包未包含或修改小熊原图；场景背景和食材插画是新增素材。已检查 JavaScript 语法、关键 HTML ID 以及代码引用的新增素材路径；摄像头识别的最终准确率仍须在你的电脑上实测，因为不同摄像头距离、光线与手型会影响 MediaPipe 的识别结果。
